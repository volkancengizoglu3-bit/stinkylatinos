# Boss Hunter for MU Immortal

Android automation project based on the existing FarmBotInGen foundation. Boss Hunter will scan the active map for yellow-skull bosses, travel to manually selected targets, verify boss death from the minimap icon, and optionally visit a configured buff point when ATK/DEF fall below configured thresholds.

Implementation is in progress; see `docs/boss-hunter-plan.md` for the state-machine plan.
